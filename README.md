**Welcome to the Python Terminal Games repository!** 
This project serves as a practical implementation of fundamental Python concepts, focusing on terminal-based game loops, user input validation, and object-oriented interactions.

The repository is structured into two main directories:
- **individual_games/**: Standalone terminal implementations of popular games—such as Blackjack, Slots, and Rock-Paper-Scissors—designed for easy inspection, testing, and modification.
- **python_casino/**: A unified application that ties all games together into an interactive arcade system. It features:
    * In-Game Economy: A virtual currency and purchase system.
    * Persistent Storage: Local game saving and state management using JSON files.
    * Customization: Basic options to customize user profiles and settings.

Comprehensive setup instructions, dependencies, and execution guidelines are detailed below in this README.md:

- python_casino/: Contains multiple iterative releases (pycasV1, pycasV2, etc.). The most up-to-date release is always located in latest_version/. To run it, download all files from latest_version/ and place any custom modules from implemented_games/ into the same directory as main.py.

- individual_games/: Standalone scripts that are ready to play out of the box. Simply download the latest version of your chosen game and execute the file.

Note: Earlier version iterations (V1, V2, etc.) are preserved for reference but may contain bugs, unoptimized code, or inconsistent behavior. For the best experience, always use the latest release.
